# Right Arm Curl 정상 조건 검증 결과

## 검증 개요

- 검증일: 2026-07-28
- 운동: Right Arm Curl
- 테스트 ID: `curl-normal-test`
- 테스트 조건: `normal`
- 기준 결과: JSON 스냅샷
- 실제 완료 횟수: 10회
- 예측 횟수: 10회
- 절대 횟수 오차: 0회

이 문서는 실시간 자세 추정 결과를 운동 횟수로 변환하는 영상 분석 알고리즘이
어떤 문제를 해결했고, 정상 조건 단일 테스트에서 무엇을 확인했는지 기록한다.

## 해결하려던 문제

MoveNet은 매 프레임 인체 관절 좌표와 confidence를 출력하지만,
실제 카메라 환경에서는 다음 문제 때문에 좌표를 그대로 횟수 판정에 사용할 수 없다.

- 관절 좌표의 프레임 간 흔들림
- 관절 가림과 화면 이탈로 인한 낮은 confidence
- 임계값 주변 노이즈에 의한 중복 상태 전이
- 불완전하게 굽힌 동작의 오인식 가능성
- 관절 재검출 시 발생하는 비현실적인 각속도
- 조도와 흐림에 따른 입력 영상 품질 변화

핵심 문제는 다음과 같이 정의했다.

> 불완전하고 흔들리는 AI 관절 추정 결과를 어떻게 신뢰 가능한 운동 횟수로 변환할 것인가?

## 적용한 해결 방법

```text
웹캠 프레임
  → MoveNet 관절 추정
  → 필수 관절 confidence·화면 범위 검증
  → EMA 관절 좌표 평활화
  → 벡터 내적 기반 관절 각도 계산
  → 시간 간격·최대값 기반 각속도 이상치 필터
  → 유지시간·히스테리시스 기반 반복 횟수 상태 머신
  → OpenCV 입력 영상 품질 분석
  → 정확도·성능 결과 저장
```

OpenCV는 횟수를 직접 판정하지 않는다.
입력 영상의 밝기와 선명도를 측정해 관절 검출 문제와 촬영 환경 문제를 구분하는 보조 분석에 사용한다.

## 검증 과정

초기 테스트에서는 실제로 수행한 10회를 시스템도 10회로 판정했지만,
실제 횟수 입력란이 비어 있어 애플리케이션이 절대 오차를 계산하지 못했다.

첫 공식 재검증에서는 실제 횟수와 오차가 저장됐지만,
카메라를 정지한 뒤 결과를 내보내 OpenCV 밝기와 선명도 값이 초기화됐다.

최종 재검증에서는 다음 절차를 적용했다.

1. 테스트 ID와 조건 입력
2. Right Arm Curl 완전 동작 10회 수행
3. 사람이 직접 확인한 실제 완료 횟수 `10` 입력
4. 카메라를 정지하지 않은 상태에서 JSON 저장
5. 이어서 CSV 저장
6. 저장된 파일을 다시 파싱해 필드와 원시 표본 수 확인

남은 유효 관절 데이터로 실제 10회를 10회로 판정했다.

이 결과는 모든 프레임을 무조건 신뢰하지 않고

## JSON과 CSV 스냅샷 차이

JSON과 CSV는 각각 다른 버튼을 눌러 저장하며,
버튼을 누르는 순간마다 새로운 결과 스냅샷을 생성한다.

이번 테스트에서는 두 파일의 생성 시점이 약 2.72초 차이 났고,
그동안 카메라 분석이 계속되어 다음 값이 달라졌다.

| 항목 | JSON | CSV |
|---|---:|---:|
| 실행시간 | 73.4초 | 76.1초 |
| 처리 프레임 | 3,682 | 3,843 |
| 무효 프레임 | 816 | 977 |
| 유효 관절 검출률 | 77.8% | 74.6% |
| 밝기 | 90.77 | 91.61 |
| 선명도 | 2,774.56 | 2,770.33 |

실제 횟수, 예측 횟수, 절대 오차와 테스트 조건은 두 파일에서 일치했다.
포트폴리오의 대표 결과는 먼저 저장되고 원시 표본을 포함한 JSON을 기준으로 한다.

이 차이는 처리속도 문제가 아니라 서로 다른 시점의 독립 스냅샷이라는 의미다.
향후 필요하면 하나의 고정 스냅샷에서 JSON과 CSV를 동시에 생성하도록 개선할 수 있지만,
현재 영상 알고리즘 검증의 우선 과제는 아니다.

## 이번 결과가 보여주는 것

1. 정상 팔 컬 단일 테스트에서 실제 10회와 예측 10회가 일치했다.
2. 전체 프레임 중 22.2%를 무효로 제외하면서도 완전 동작을 판정했다.
3. 추론 오류 없이 실시간 카메라 파이프라인이 동작했다.
4. 평균·P50·P95·최대 처리시간을 원시 표본 3,000개와 함께 기록했다.
5. OpenCV로 정상 조건의 밝기와 선명도 기준값을 수치화했다.
6. 실제 횟수, 예측 횟수와 절대 오차를 JSON/CSV로 재현 가능하게 저장했다.

## 포트폴리오용 요약

> 실시간 자세 추정에서는 관절 가림과 좌표 흔들림으로 모든 프레임을 운동 판정에 사용할 수 없었다. 필수 관절 confidence 검사, EMA 평활화, 각속도 이상치 필터와 유지시간·히스테리시스 기반 상태 머신을 구현해 유효한 동작만 판정했다. 정상 팔 컬 단일 테스트에서 전체 프레임의 22.2%가 무효로 제외됐음에도 실제 10회를 10회로 측정했으며, 평균 추론시간 15.51ms, P95 18.50ms, 추론 오류 0건을 기록했다. OpenCV 기반 밝기와 선명도 측정을 함께 저장해 입력 영상 품질도 수치로 관리했다.
