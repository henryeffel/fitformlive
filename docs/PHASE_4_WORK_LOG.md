# Phase 4 작업 로그

## 작업 개요

- 작업일: 2026-07-27
- Phase: 4 — 제한된 기능 검증
- 기준 문서: `docs/VIDEO_ALGORITHM_DEVELOPMENT_PLAN.md`
- 상태: 검증 도구와 프로토콜 구현 완료, 실제 웹캠 테스트 실행 대기

## 이번 작업의 범위

Phase 4는 실제 사용자가 웹캠 앞에서 운동해야 완료할 수 있다. 이번 작업에서는 동일한 조건으로 결과를 수집하고 비교할 수 있는 검증 도구와 절차를 구현했다.

실제 운동 결과나 성능 수치는 임의로 작성하지 않았다.

## 구현 내용

### 개발자 도구 검증 입력 UI

다음 입력 항목을 추가했다.

- 테스트 ID
- 테스트 조건
- 실제 수행 횟수
- 테스트 메모

지원하는 조건:

- 정상 환경
- 동작 범위 부족
- 빠른 동작
- 낮은 조도
- 관절 일부 가림
- 거리 변화

### 횟수 오차 자동 계산

실제 횟수가 입력되면 다음 값을 계산한다.

```text
absoluteError = |predictedReps - trueReps|
```

함께 계산하는 값:

- 정확 일치 여부
- ±1회 이내 여부
- 앱이 측정한 횟수

이 값은 개발자 도구에 실시간 표시된다.

### JSON 결과 확장

기존 성능 보고서에 `validation` 객체를 추가했다.

```json
{
  "testId": "curl-normal-01",
  "condition": "normal",
  "trueReps": 10,
  "predictedReps": 10,
  "absoluteError": 0,
  "exactMatch": true,
  "withinOneRep": true,
  "notes": null
}
```

### CSV 결과 확장

다음 열을 추가했다.

- `test_id`
- `test_condition`
- `true_reps`
- `predicted_reps`
- `absolute_error`
- `exact_match`
- `within_one_rep`
- `notes`

### 테스트 프로토콜

다음 문서를 생성했다.

- `docs/MANUAL_TEST_PROTOCOL.md`

포함된 시나리오:

1. 정상 팔 컬 10회
2. 동작 범위가 부족한 팔 컬
3. 빠른 팔 컬
4. 낮은 조도
5. 손목 또는 팔꿈치 가림
6. 카메라 거리 변화
7. 정상 스쿼트 10회

### 결과 템플릿

다음 파일을 생성했다.

- `evaluation/test-results-template.csv`

테스트별 빈 행과 성능 지표 열을 제공하여 앱에서 내려받은 결과를 하나의 표로 정리할 수 있게 했다.

### 결과 디렉터리 보호

`evaluation/results/`를 만들고 `.gitkeep`만 추적한다.

실제 JSON/CSV 결과에는 환경 정보와 메모가 들어갈 수 있으므로 기본적으로 Git에서 제외한다.

개인 얼굴이 포함된 원본 영상은 저장소에 커밋하지 않는다.
